# 실측 파라미터 입력표

단위는 Xacro 기준으로 길이 `m`, 질량 `kg`, 각도 `rad`입니다. 현재 기구 실측값은 `urdf/robot_parameters.xacro`에 반영 완료했습니다.

## 스프레드시트에서 확인된 값

- 카메라: Intel RealSense D405, 외형 약 `42 x 42 x 23 mm`
- LiDAR: Livox Mid-360, 외형 `65 x 65 x 60 mm`, 질량 `0.265 kg`
- 모터: DYNAMIXEL XL430-W250-T
- 바퀴 실측 지름: `95.5 mm` → 초기 Xacro 반지름 `0.04775 m`
- 타이어 한 개의 고무 폭: `11.3 mm` → Xacro `wheel_width = 0.0113 m`
- 좌우 고무 바깥쪽 간격: `159.5 mm` → 바퀴 중심 간격 `159.5 - 11.3 = 148.2 mm`, Xacro `wheel_separation = 0.1482 m`
- 한쪽 바퀴 회전부 질량: `115 g` → `wheel_mass = 0.115 kg`. 고무 타이어, 휠/허브, 바퀴측 출력기어 및 함께 회전하는 볼트·축 부품 포함
- 외부 기어: `2:1 증속`. 모터 1회전당 바퀴 2회전이므로 회전수 비의 크기는 `motor revolution / wheel revolution = 0.5`. 직접 맞물린 외접기어 한 쌍의 회전 방향 반전도 펌웨어에 반영
- 센서와 바퀴를 포함한 완성 로봇 실측 질량: `2.215 kg`
- Onshape 바퀴 제외 고정부 질량: `1.939969 kg`. 스페이서·볼트·커넥터 일부를 생략한 CAD 모델값
- 현재 URDF 모델 질량: `1.939969 + 2*0.115 = 2.169969 kg`
- 배터리: LiPo `11.1 V`, `7200 mAh`, 높이 `25 mm`
- 전원 계산: 총 `65.80 W`, 예상 전류 `5.93 A`, 예상 구동시간 약 `1 h 13 min`
- 적층 계획: 1층 캐스터/배터리, 2층 모터, 3층 NUC/OpenCR, 4층 LiDAR, 전면 카메라

적층 계획의 높이만 더해서 TF 좌표를 만들지는 않았습니다. 플레이트 두께, 스페이서, 브래킷과 `base_link` 기준점이 시트에 없기 때문입니다.

## 반드시 입력할 실측값

| Xacro 속성 | 측정 방법 |
|---|---|
| `wheel_radius` | 현재 실측 지름 95.5 mm로 `0.04775 m` 입력. 완성 후 직선 주행거리로 유효 반지름 재보정 |
| `wheel_width` | 실측 고무 폭 `0.0113 m` 입력 완료. 돌출 볼트 머리는 제외하고 별도의 전체 외곽 폭에 포함 |
| `wheel_separation` | 실측값으로 계산한 중심면 간 거리 `0.1482 m` 입력 완료 |
| `wheel_x` | `base_link` 원점에서 바퀴 축까지의 x 오프셋 |
| `wheel_mass` | 고무 타이어·휠/허브·출력기어·함께 회전하는 체결부를 포함한 한쪽 회전부. 실측 `0.115 kg` 입력 완료 |
| `base_length/width/height` | 실측 여섯 방향 경계로 계산한 차체 collision `0.185718 × 0.1222 × 0.159081 m` 적용 완료 |
| `base_x/base_y/base_z` | 위 collision 중심 `(-0.025214, 0, 0.0389905) m` 적용 완료 |
| `base_visual_mesh_*` | Assembly 원점 기준 STL을 `base_link`로 이동·회전하는 pose와 `scale=1` 적용 완료 |
| `base_mass` | Onshape 바퀴 제외 고정부 전체 `1.939969 kg` 적용 완료. D405·Mid-360·캐스터를 포함한 값 |
| `base_com_x/y/z` | Onshape `base_link` 기준 고정부 COM `(-0.031713, 0.000047, 0.040927) m` 적용 완료 |
| `base_ixx...izz` | Onshape의 `base_link` 기준 행렬을 평행축 정리로 COM 기준 변환하여 적용 완료 |
| `footprint_front/rear/left/right` | 전체 외곽 실측값 `(67.645, 118.073, 90.3, 90.3) mm` 적용 완료 |
| `robot_radius` | 외곽 직사각형의 가장 먼 모서리 `148.645 mm`를 보수적으로 올린 `0.149 m` 적용 |
| `caster_x/y` | 좌우 바퀴 축 중앙에서 볼 중심까지의 평면 오프셋. 실측 `(-0.079073, 0) m` 입력 완료 |
| `caster_radius/z` | 볼 지름 `4.7625 mm`에서 반지름 `0.00238125 m`를 적용. 바닥 접촉 조건으로 중심 z 자동 계산 |
| `lidar_x/y/z` | 밑면 중심 `(-0.033073, 0, 0.0969) m`에서 계산한 점군 원점 `(-0.033073, 0, 0.1439) m` 적용 완료 |
| `lidar_roll/pitch/yaw` | M12 커넥터 후방, 수평 정방향이므로 `(0, 0, 0) rad` 적용 완료 |
| `camera_x/y/z` | 뒤쪽 M3 장착점과 D405 기구 치수로 계산 완료: 약 `(0.058026, 0.009000, 0.083634) m` |
| `camera_roll/pitch/yaw` | 정상 방향, 아래보기 17도로 입력 완료: `(0, 0.296706, 0) rad` |

좌표계는 REP-103을 따릅니다: `+x` 전방, `+y` 좌측, `+z` 위. `camera_optical_frame`은 Xacro에서 `+z` 전방, `+x` 우측, `+y` 아래로 자동 변환합니다.

## 실측 기준점

이 모델의 `base_link` 원점은 좌우 바퀴 축 중심을 연결한 선의 정중앙입니다. 따라서 다음처럼 재면 됩니다.

- x: 바퀴 축 중심을 지나는 수직면에서 앞쪽이 양수, 뒤쪽이 음수
- y: 로봇 정중앙선에서 왼쪽이 양수, 오른쪽이 음수
- z: 바퀴 축 높이에서 위쪽이 양수. 바닥에서 높이를 잰 경우 `z = 바닥 기준 높이 - 0.04775 m`
- 캐스터: 축 중앙에서 캐스터가 바닥에 닿는 점의 중심까지 x/y를 측정
- 바퀴 중심 간격: 좌우 고무 타이어의 중심면 사이 거리. 대칭 바퀴라면 `고무 바깥쪽-바깥쪽 전체 폭 - 타이어 한 개의 고무 폭`
- 돌출 볼트: `wheel_width`에는 넣지 않고 로봇 전체 최대 폭과 navigation footprint/collision 여유에는 포함

Mid-360의 점군 원점 O는 본체 평면 중심이며 밑면에서 약 `47 mm` 위에 있습니다. D405는 왼쪽 영상 센서의 렌즈 중심을 광학 원점의 실측 기준으로 사용하고, 최종 영상 보정에는 장치가 발행하는 `camera_info`를 사용합니다.

## Xacro 밖에서 나중에 필요한 값

- Mid-360 실제 IP, 호스트 Ethernet 고정 IP
- D405 시리얼 번호(카메라가 한 대뿐이면 생략 가능)

외부 기어 보정과 새 바퀴 치수는 `firmware/custom_autorace_core`의 커스텀 OpenCR 스케치에 반영했습니다. 명령 변환과 encoder-to-odom을 둘 다 보정하며 ROBOTIS 라이브러리 원본은 수정하지 않습니다.

기어가 맞물린 두 평기어라면 `모터 회전수 / 바퀴 회전수 = 바퀴측 톱니 수 / 모터측 톱니 수`입니다. 현재 구조는 바퀴가 모터보다 2배 빨리 도는 증속이므로 보정계수는 `0.5`입니다.

## 현재 적용값 요약

모든 좌표는 `base_link` 기준입니다. `base_link`는 좌우 바퀴 회전축 중심의 정중앙이며 `+x`는 전방, `+y`는 왼쪽, `+z`는 위쪽입니다.

| 요소 | 원본/실측값 | Xacro·펌웨어 적용값 | 상태 |

왼쪽 바퀴의 Onshape 관성은 `base_link` 기준이므로 COM으로 평행 이동한 뒤, 바퀴 링크의 local `+z`가 회전축을 향하도록 좌표축을 변환했습니다. 바퀴 조인트 중심은 `y=+74.1 mm`이고 출력기어 때문에 왼쪽 회전부 COM은 안쪽으로 `1.011 mm` 이동해 있습니다. 오른쪽은 동일한 회전부가 좌우 대칭으로 장착된 것으로 적용합니다.

```text
왼쪽 wheel link 기준 COM (m)
  (0.000004, 0.000004, -0.001011)

왼쪽 wheel link의 COM 기준 관성행렬 (kg·m²)
  [ 0.000077083887   0.000000000002  -0.000000007585 ]
  [ 0.000000000002   0.000077083887  -0.000000007581 ]
  [-0.000000007585  -0.000000007581   0.000145643797 ]

오른쪽 wheel link 기준 COM (m)
  (0.000004, 0.000004, 0.001011)

오른쪽은 좌우 대칭이므로 ixz와 iyz의 부호가 반대입니다.
```

### RealSense D405

카메라는 렌즈가 로봇 전방을 향하고, 1/4-20 구멍 면이 아래이며, 뒤쪽 로고가 정상으로 읽히는 방향입니다. 본체는 로봇 좌우 중앙에 있고 아래보기 각도만 `17 deg`입니다.

| 요소 | 값 | 설명 |
|---|---:|---|
| 뒤쪽 M3 장착 기준점 | `(39.665, 0, 89.248) mm` | 수정된 어셈블리 기준 x/z를 사용하고 y는 두 M3 구멍의 정중앙으로 정의 |
| 장착 자세 RPY | `(0, 17, 0) deg` | Xacro에서는 `(0, 0.296706, 0) rad` |
| M3 기준점 → 광학 원점 | `(19.2, 9.0, 0) mm` | D405 본체 좌표, left imager 깊이 원점 기준 |
| 회전 후 광학 원점 오프셋 | `(18.361, 9.0, -5.614) mm` | 17 deg pitch 적용 결과 |
| 최종 광학 원점 | `(58.026, 9.000, 83.634) mm` | `camera_frame` 및 `camera_optical_frame`의 위치 기준 |
| 최종 Xacro 좌표 | `(0.058026, 0.009000, 0.083634) m` | `camera_x/y/z` 계산 결과 |
| 카메라 외형 | `23 x 42 x 42 mm` | x=깊이, y=폭, z=높이인 box 근사 |
| 카메라 입력 | `1280 x 720 @ 30 Hz` | Gazebo 및 D405 bringup 기본값 |
| 수평 FOV | 약 `87 deg` | `camera_horizontal_fov = 1.5184364 rad` |

광학 원점 계산식은 다음과 같습니다. 여기서 `R`은 `Rz(yaw) * Ry(pitch) * Rx(roll)`입니다.

```text
p_optical = p_M3_midpoint + R * p_offset

p_M3_midpoint = (39.665, 0, 89.248) mm
p_offset      = (19.2, 9.0, 0) mm
RPY           = (0, 17, 0) deg

p_optical     = (58.026, 9.000, 83.634) mm
```

카메라 본체 중심은 `y=0`을 유지합니다. `camera_frame`이 left-imager 광학 원점에 있으므로 visual/collision 본체 중심은 광학 원점에서 `(-7.7, -9.0, 0) mm` 오프셋으로 배치합니다.
