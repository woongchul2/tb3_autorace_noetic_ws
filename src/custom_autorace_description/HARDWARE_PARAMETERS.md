# 하드웨어 파라미터 원장

이 문서는 로봇의 실측값과 그로부터 계산한 적용값을 한곳에서 관리하는 기준 문서입니다. 실행값은 [`urdf/robot_parameters.xacro`](urdf/robot_parameters.xacro)와 `firmware/custom_autorace_core`에 반영되어 있습니다. 값을 바꿀 때는 이 문서와 해당 실행값을 같은 변경에서 갱신합니다.

- 길이: `m` 또는 표에 명시한 `mm`
- 질량: `kg`
- 각도: `rad` 또는 표에 명시한 `deg`
- 좌표: REP-103, `base_link` 기준 `+x` 전방, `+y` 좌측, `+z` 위
- `base_link`: 좌우 바퀴 회전축 중심을 연결한 선의 정중앙

기구 실측값은 반영 완료했습니다. 센서 시뮬레이션 사양, 네트워크 값과 주행 기반 보정값은 아래의 미확정 항목에 구분해 둡니다.

## 바퀴와 구동부

| 항목 | 근거 | 적용값 | 상태 |
|---|---:|---:|---|
| 모터 | DYNAMIXEL XL430-W250-T | XL430-W250-T | 확정 |
| 바퀴 지름 | `95.5 mm` | `wheel_radius = 0.04775 m` | 실측 적용 |
| 타이어 고무 폭 | `11.3 mm` | `wheel_width = 0.0113 m` | 실측 적용 |
| 고무 바깥쪽 전체 폭 | `159.5 mm` | 중심 간격 `159.5 - 11.3 = 148.2 mm` | 실측 적용 |
| 바퀴 중심 간격 | `148.2 mm` | `wheel_separation = 0.1482 m` | 계산 적용 |
| 바퀴 축 x 오프셋 | `base_link`가 축 중앙 | `wheel_x = 0 m` | 적용 |
| 한쪽 회전부 질량 | `115 g` | `wheel_mass = 0.115 kg` | 실측 적용 |
| 외부 기어 | 바퀴가 모터보다 2배 빠른 외접 평기어 | `GEAR_SPEEDUP = 2.0`, `GEAR_DIRECTION = -1.0` | 펌웨어 적용 |
| 모터/바퀴 회전수 비 | `motor revolution / wheel revolution` | 크기 `0.5` | 계산 적용 |

`wheel_mass`에는 고무 타이어, 휠·허브, 바퀴측 출력기어와 함께 회전하는 체결부가 포함됩니다. 외접기어 방향 반전은 명령 변환과 encoder-to-odom 양쪽에 적용하며 ROBOTIS 원본은 수정하지 않습니다.

왼쪽 Onshape 값을 COM 기준으로 평행 이동한 뒤 wheel-link 축으로 변환한 관성값은 다음과 같습니다. 오른쪽은 좌우 대칭이므로 `ixz`, `iyz` 부호가 반대입니다.

```text
왼쪽 wheel link 기준 COM (m)
  (0.000004, 0.000004, -0.001011)

왼쪽 wheel link의 COM 기준 관성행렬 (kg·m²)
  [ 0.000077083887   0.000000000002  -0.000000007585 ]
  [ 0.000000000002   0.000077083887  -0.000000007581 ]
  [-0.000000007585  -0.000000007581   0.000145643797 ]

오른쪽 wheel link 기준 COM (m)
  (0.000004, 0.000004, 0.001011)
```

원본 왼쪽 회전부 COM은 `base_link` 기준 `(0.004, 73.089, -0.004) mm`이고 조인트 중심은 `y=+74.1 mm`입니다. 따라서 출력기어를 포함한 회전부 COM은 바퀴 중심보다 안쪽으로 `1.011 mm` 이동해 있습니다.

```text
고정부 COM 기준 관성행렬 (kg·m²)
  [ 0.005943510  -0.000005377  -0.000309921 ]
  [-0.000005377   0.007039460  -0.000009725 ]
  [-0.000309921  -0.000009725   0.004035941 ]
```

고정부 visual은 `custom_autorace_fixed.stl`을 사용합니다. STL 정점은 이미 m 단위이며, Assembly 원점 기준 `base_link = (-165.482, -186.000, 58.854) mm`입니다.

## RealSense D405

카메라는 렌즈가 전방을 향하고 1/4-20 구멍 면이 아래인 정상 방향이며, 로봇 좌우 중앙에서 아래로 `17 deg` 기울어져 있습니다. 광학 원점은 왼쪽 영상 센서의 렌즈 중심입니다.

| 항목 | 적용값 | 근거·상태 |
|---|---:|---|
| 본체 외형 | `23 × 42 × 42 mm` | x=깊이, y=폭, z=높이 box 근사 |
| 뒤쪽 M3 장착 기준점 | `(39.665, 0, 89.248) mm` | 두 M3 구멍 정중앙 |
| 장착 RPY | `(0, 17, 0) deg` | Xacro `(0, 0.296706, 0) rad` |
| M3 기준점→광학 원점 | `(19.2, 9.0, 0) mm` | D405 본체 좌표 |
| 회전 후 광학 오프셋 | `(18.361, 9.0, -5.614) mm` | 17 deg pitch 적용 |
| 최종 광학 원점 | `(58.026, 9.000, 83.634) mm` | `camera_x/y/z` 기준 |
| 본체 중심 오프셋 | `(-7.7, -9.0, 0) mm` | 광학 원점 기준 |
| 수평 FOV | 약 `87 deg` | `1.5184364 rad` |
| 실물 기본 입력 | `1280 × 720 @ 30 Hz` | D405 bringup |

광학 원점은 `p_optical = p_M3_midpoint + R × p_offset`으로 계산하며, `R = Rz(yaw) × Ry(pitch) × Rx(roll)`입니다. `camera_optical_frame`은 Xacro에서 `+z` 전방, `+x` 우측, `+y` 아래로 변환합니다. 최종 영상 보정은 장치가 발행하는 `camera_info`를 사용합니다.

## 측정 규칙

- x는 바퀴 축 중심 수직면에서 앞쪽이 양수, 뒤쪽이 음수입니다.
- y는 로봇 정중앙선에서 왼쪽이 양수, 오른쪽이 음수입니다.
- z는 바퀴 축 높이에서 위쪽이 양수입니다. 바닥 기준 높이는 `z = 측정 높이 - 0.04775 m`로 변환합니다.
- 바퀴 중심 간격은 `고무 바깥쪽 전체 폭 - 타이어 한 개의 고무 폭`으로 계산합니다.
- 돌출 볼트는 `wheel_width`가 아니라 전체 footprint와 collision 여유에 포함합니다.
